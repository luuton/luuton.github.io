# DSP 系统结构图制图规范

用于第 4 章「数字滤波器的网络结构」的方框图与信号流图。所有图由
`figs.py` 生成一份几何数据（`figures.json`），再由两个后端渲染：

| 后端 | 用途 | 命令 |
|---|---|---|
| `svg.py` | 实际出图（矢量，任意缩放清晰） | `python svg.py` |
| `draw_sfg.m` | MATLAB 重绘（同源几何，便于二次修改） | `matlab -batch "draw_sfg"` |

`check.py` 做几何自检：支路必须水平/垂直、两两不相交、文字不压线。

## 1. 图形语言

- **节点**：实心圆，`r = 0.06`（单位：英寸）。变量名（信号名）标在节点旁。
- **支路**：正交折线，线宽 `0.017`，末端实心三角箭头（长 `0.155`、半宽 `0.082`）。
- **增益**：标在支路水平段上方居中；数字用正体，变量名用斜体。
- **延迟**：方框内写 `z⁻¹`（直接型方框图）或作为支路增益 `z⁻¹`（纯信号流图）。
- **求和**：圆圈内写 `Σ`，半径 `0.24`。
- **字体**：Times New Roman（数学符号）与正文一致，字号 0.135–0.155 英寸。

## 2. 布局规则

1. **主干水平**：一条延迟链的所有节点落在同一条水平线上，间距 `1.30`。
2. **抽头先竖直、再水平**：从链上节点竖直离开，到指定层高后水平汇入母线。
3. **同侧分层不交叉**：同一侧的多个抽头，离所属链越近的抽头，其水平段也越靠近该链。
   前馈抽头（来自 x 链）向下分层，反馈抽头（来自 y 链）向上分层。
4. **母线**：所有抽头汇入一根竖直短线；`Σ` 圆画在母线上并留出缺口，避免线穿圆心。
5. **直接 Ⅱ 型**：输入求和点在左、输出求和点在右上；反馈走下方、输出走上方。
6. **不要斜线**、不要让两支路在非端点处交叉、不要让文字压在线上——由 `check.py` 保证。

## 3. 与教材符号的对应

| 图形 | 教材叫法 | 延迟单元数 |
|---|---|---|
| 直接 Ⅰ 型 | 直接型 / 卷积型 | `M + N` |
| 直接 Ⅱ 型 | 典范型 / 正准型 | `max(M, N)` |
| 级联型 | 串联型 | `N` |
| 并联型 | 部分分式型 | `N` |
| 线性相位型 | — | `N/2` |

图中 `M` 为分子阶数、`N` 为分母阶数。习题 4.3 的 `H(z)` 是 `M=1, N=2`，
所以直接 Ⅰ 型三个延迟、直接 Ⅱ 型两个；习题 4.4 是 `M=2, N=3`，
对应五个和三个。

## 4. 工作流

```bash
cd scripts/dsp/sfg
python figs.py        # 结构参数 -> figures.json（绝对坐标图元表）
python svg.py         # figures.json -> out/*.svg
python check.py       # 几何自检：正交、不交叉、不穿框、文字不压线
node shot.mjs         # 可选：用无头 Edge 把 out/*.svg 渲染成 PNG 校对
cp out/*.svg ../../../public/images/dsp/struct/
```

文章通过 `/images/dsp/struct/<name>.svg` 引用。SVG 用纯黑绘制、无背景，
暗色模式下由 `src/styles/markdown.css` 里的
`:root.dark .custom-md img[src$=".svg"] { filter: invert(0.88) hue-rotate(180deg) }`
反色显示。

## 5. 为什么用 SVG 而不是 MATLAB 出图

`draw_sfg.m` 保留完整实现，读取同一份 `figures.json`，在有 MATLAB 许可的机器上
可直接生成 PNG。本机 MATLAB R2024b 因在线许可无法连接 MathWorks（错误 5201）
而无法启动，所以实际出图走 SVG 后端；两者几何完全同源，互换不影响排版。
